# Rift Cut

One-button neon flyer. Hold to climb, release to fall, cut through the gates.

## Play

- GitHub Pages: https://chive55.github.io/rift-cut/
- Instant preview: https://htmlpreview.github.io/?https://github.com/chive55/rift-cut/blob/main/index.html

## Controls

- Hold click / tap / Space / Up to climb
- Release to fall
- Thread the glowing gap in each gate

Best score is stored in the browser (`localStorage`).
